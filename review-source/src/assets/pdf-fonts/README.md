Tinos Regular/Bold are embedded in PDF exports for Vietnamese text and a serif appearance compatible with Times New Roman.

Source: https://github.com/google/fonts/tree/main/ofl/tinos
License: SIL Open Font License 1.1, see OFL.txt from https://github.com/googlefonts/tinos/blob/main/OFL.txt.

The .base64 files contain the unchanged TTF font bytes for offline exports from the single-file HTML build.
